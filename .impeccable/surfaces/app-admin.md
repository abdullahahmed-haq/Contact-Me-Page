# Connect Studio visual contract

Mode: Operate. The owner updates bilingual content, previews the actual public page and publishes deliberately. This is a new administrative surface inside the established Pastel Contact Bento world.

Cream surfaces, botanical ink, quiet sage active states, original self-hosted Manrope/Noto Sans Arabic, soft depth and 12–16px panel corners carry the identity. Public card geometry, artwork, gradients and placement remain governed by DESIGN.md. The dashboard uses restrained color and familiar controls for density and scanability.

Desktop: a fixed 236px sidebar, 72px top bar, compact page title, persistent draft/publication status strip and a flexible form workspace. Primary publishing stays beside Save draft; individual screens contain real content editors and service states. Live preview opens a shared-component iframe beside the editor at wide widths and above it on narrower screens. The dashboard opens with a profile greeting and actual content counts, followed by an honest analytics empty state and real activity.

Mobile/tablet: sidebar becomes an overlay with backdrop dismissal, publication actions wrap, forms preserve paired locale editing until the narrowest width, long data wraps and navigation remains one touch away. RTL uses logical properties and the Arabic typeface, including menu placement and field direction. Preview language is independent of editor language.

Signature interaction: edits flow into the exact public ConnectPage and contact sheets before publication. Saved drafts, published snapshots and unsaved changes have distinct status. Errors identify validation paths; actions show success/failure feedback; conflicting saves do not silently overwrite.

Finish evidence: desktop and mobile dashboard screenshots, Arabic mobile screenshot, existing public responsive/interaction tests, and an independent finish review. No new shipping raster assets were created; the original avatar provenance files remain intact.
